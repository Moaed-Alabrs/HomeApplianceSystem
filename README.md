# Home Appliance System

A console application for managing home appliances, maintenance status, and estimated repair costs.

## Requirements

- Windows, macOS, or Linux
- .NET 9 SDK

Verify that the .NET SDK is installed:

```bash
dotnet --version
```

The reported version must be `9.0` or later within the .NET 9 SDK family. The .NET Runtime alone is not sufficient; the SDK is required to restore and build the project.

## Getting started

1. Clone or download this repository.
2. Open a terminal in the repository root, the directory containing `HomeApplianceSystem.csproj`.
3. Restore the project dependencies:

   ```bash
   dotnet restore
   ```

   This creates `obj/project.assets.json`. The `obj` and `bin` folders are generated build folders and are not intended to be committed to the repository.

4. Build the application:

   ```bash
   dotnet build
   ```

5. Launch the application:

   ```bash
   dotnet run
   ```

You can also run the project explicitly from another directory:

```bash
dotnet run --project path/to/HomeApplianceSystem.csproj
```

## Running from Visual Studio

1. Install Visual Studio with the **.NET desktop development** workload and .NET 9 SDK support.
2. Open `HomeApplianceSystem.csproj`.
3. If prompted, allow Visual Studio to restore NuGet packages.
4. If no prompt appears, right-click the project in **Solution Explorer** and select **Restore NuGet Packages**.
5. Select the project as the startup project if necessary.
6. Press **Ctrl+F5** to run without debugging or **F5** to run with debugging.

## Using the application

After launch, select an option from the menu:

1. Add an appliance
2. Show all appliances
3. Show summary
4. Update appliance status
5. Exit

The application supports refrigerators, washing machines, and air conditioners. Appliance data is stored in memory while the application is running and is not persisted after exit.

## Troubleshooting

### `project.assets.json` not found

Run the following commands from the repository root:

```bash
dotnet restore HomeApplianceSystem.csproj
dotnet build HomeApplianceSystem.csproj
dotnet run --project HomeApplianceSystem.csproj
```

If the error continues, close Visual Studio, remove the generated `bin` and `obj` folders, reopen the project, and restore again:

```powershell
Remove-Item -Recurse -Force .\bin, .\obj
dotnet restore .\HomeApplianceSystem.csproj
dotnet run --project .\HomeApplianceSystem.csproj
```

Do not manually create `project.assets.json`; it is generated by `dotnet restore`.

### `dotnet` is not recognized or the target framework is unavailable

Install the .NET 9 SDK from the official .NET download page, then restart the terminal or Visual Studio and run:

```bash
dotnet --info
```

### The application does not accept keyboard input

Run it in a terminal or Visual Studio's console window. This is an interactive console application and requires keyboard input.
